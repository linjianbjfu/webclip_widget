# AGENTS.md — Agent Notes

Agent Note 本质上是由 agent 写的 RFC：持久的提案和决策记录，保存理由、替代方案、后果和必需的验证手段。遵循 [Agent Note 规则](README.md)。

**每一篇新的 Agent Note 都触发一次取代检查。** 在活跃树里搜索覆盖同一决策或同一机制的旧笔记，用 [`archive-agent-notes`](../skills/archive-agent-notes/SKILL.md) 判定完全取代还是部分取代，并在同一个 PR 里归档每一篇够格的笔记。部分取代的保持活跃并互相链接。

[`archived/`](archived/AGENTS.md) 下的文件是冻结的历史快照：永远不要编辑它们，也不要把它们当作当前行为的依据。
