# Agent Note: 精简选区 DOM 与原 URL 数据预览

Status: implemented

## 问题

框选后仍上传整页 DOM，模型检索会遇到导航、脚本及无关内容。当前 preview 默认加载捕获 HTML；这个副本无法完整恢复原网页的 origin、脚本环境和最新数据，精简 DOM 后更不能作为原网页运行环境。

capture/capture.json 保存捕获时的最终 pageUrl、初始 requestUrl 和 baseUrl；preview 需要复用最终地址，避免另存重复配置。精简需要保持选区定位与真实页面对应，不能把兄弟删除后的新序号或新形成的 id 唯一性交给模型猜测转换。

## 决策

### 保留前方定位结构，删除后方无关分支

有选区时，完整保留各选区子树，包括元素、命名空间、属性、文本、注释、链接、图片、SVG 和脚本数据。多选取内容保留范围的并集，重叠时不复制元素。选区到 document 根的祖先链保留，并按以下规则处理祖先的子节点：

- 包含任意选区的分支必须保留，递归处理；到达选区根后停止裁剪其内部。
- 在最后一个包含选区的子分支之前，保留所有兄弟元素的结构、原属性及顺序；不含选区的这些分支仅清除 Text/Comment 节点，其内部元素也保留，不用虚构节点占位。
- 在最后一个包含选区的子分支之后，删除全部无关兄弟分支；这部分不可能包含其他选区。
- 所有保留分支内，选区之外的 Text/Comment 节点移除，因此外围文字、script/style 正文和注释不进入 source.html。

例如 root 下依次是导航、广告、选中新闻、更多内容：保留导航/广告的元素结构，清除其文字，完整保留新闻，删除后方更多内容。新闻仍是第 3 个 div。若“更多内容”里还有第二个选区，则必须保留通往它的分支，以及两个选区之间用于维持位置的兄弟结构。沿祖先链逐层使用相同规则，不能单独裁剪每个选区后再拼接。

### 用正向绝对 XPath 验证原定位

精简前先生成从文档根开始、按同命名空间同名兄弟元素正向编号的绝对 XPath，例如 /html[1]/body[1]/div[1]/div[3]，不以 id 快捷路径代替。只删除后方分支，因此保留元素的父子层级、前方兄弟序号和属性不变，选区及祖先的正向 XPath、nth-child/nth-of-type 位置不因精简而变化。

删除后方分支可能减少重复 id 或 class 的匹配数量，也可能使选区成为最后一个子元素。因此不承诺全局 id/class/属性选择器的匹配集合不变，也不保证 last()、last-child、nth-last-child、following-sibling、选区外文本、text()/node() 位置、:empty、样式或脚本行为等价。source.html 用于检查选区结构和数据，视觉含义来自实时截图。

精简只在捕获文档副本上操作，不改真实页面；工具节点排除、UTF-8 charset 规范化及 HTML 解析修复沿用现有捕获流程。在临时标记完成选区映射后记录精简前的正向绝对路径，再裁剪、移除标记并重新解析验证：该路径必须在精简前后唯一命中对应区域，保留元素的层级、属性和正向位置不变，选区内容完整。验证不通过时拒绝，不能为通过检查另造精简路径或删除更多节点。

region.xpath 使用精简前已确定且精简后仍有效的正向绝对路径。实时 sourceXPath 也使用正向绝对元素路径；若运行时 HTML 因非法嵌套被解析器修复而使两者不同，仍沿用现有 sourceXPath 字段保存实时定位。这是 HTML 解析修复的既有限制，裁剪不增加一次路径转换。无选区模式仍保留完整页面内容。

server brief 说明外围内容可能清空、后方分支可能删除；extra.js 以原始正向绝对 XPath 作为选区定位依据，再在选区内提取数据。不得根据精简文档推断原网页 id 全局唯一、全局匹配数量或倒序位置，也不能依赖被删除区域或硬编码样本值。其他稳定锚点不能仅凭精简后的唯一性取代原定位。server preview_widget 在捕获 DOM 上检查提取，CLI preview 在原 URL 上检查执行；前者不能替代后者。

截图前后比较精简 source、实时选区 fingerprint、路径及 rect。清空的外围文本、脚本正文或已删除的后方分支变化，若不影响保留结构、选区内容或位置，不再导致失败；保留元素增删、移动、属性变化，以及选区内容/位置变化继续重采或拒绝。整页模式保持完整稳定性检查。debug 保存实际提交的精简 source 与同次 capture.json、图片。

### 精简效果与边界

本地新闻列表捕获为 389259 字节、1341 个元素。完整策略实测输出 232219 字节、994 个元素，体积减少约 40.3%，原正向绝对 XPath 仍命中同一区域。对照的仅文本清理基线为 260019 字节、1341 个元素，直接删除全部无关分支的方案为 202686 字节、703 个元素。体积减少不是模型延迟或 token 数同比下降的证据。

这份样本中，选区内部 SVG 的 d/points 属性值占 87238 字节。它们可能承载图形数据，不能仅凭体积大就删除。本次保留这些属性及选区数据；进一步压缩需要独立判断哪些字段只用于装饰，而不能破坏定位或可提取内容。

### preview 使用捕获时的最终 URL

继续把当前 URL 保存于 downloads/<sessionId>/capture/capture.json 的 pageUrl，作为唯一来源；无需在会话根目录重复写 url.txt 或另一个 JSON。记录的是预览确认所对应快照的最终地址，包含路径、查询和 fragment；不能用相对资源基址 baseUrl 代替导航地址。同一 session 再次捕获沿用现有 capture 目录替换流程，URL 随快照更新。

`preview --out <目录>` 默认读取 pageUrl，校验为 HTTP/HTTPS 后打开在线页面，正常执行页面脚本。等待 load 完成后固定等 5 秒，再直接执行 extra.js，将校验后的结果写入 out/data.json。后续本地 HTTP server、widget.html 的数据加载、meta 画布、就绪检查及关闭清理沿用现有流程，不重新调用模型。源页面 viewport 使用捕获 metadata 中的尺寸及 DPR 1，减少响应式 DOM 与选择时不一致；widget viewport 继续由 meta 决定。

默认路径不读取或要求 capture/source.html 存在，也不在网络失败时退回该文件。缺少 pageUrl、格式非法、导航失败或提取失败时明确报错，并保留已有 data.json。旧会话只要已有合法 pageUrl 和 viewport 即可使用，无需回补新文件。缺少 URL 的本地文件输入保留显式 `--source <原始 HTML>` 作为离线入口；显式输入优先，不读取 capture 配置，该入口也在 load 后等 5 秒。精简后的 source.html 是模型/debug 输入，不能承诺运行它能复原原网页。

### 范围与笔记归属

本记录部分取代[多区域捕获](2026-10-05-region-capture-multimodal-widget.md)的整页内容上传、[XPath 校验](../bug-fix/2026-10-06-capture-xpath-parser-repair.md)的完整文档内容稳定性范围，以及[本地预览](2026-10-05-cli-local-widget-preview.md)的默认文件来源与 3 秒等待。以上笔记其余独立理由继续有效，已同步并交叉链接，保持活跃，无归档或删除。[debug 留存](2026-10-06-local-capture-debug.md)继续拥有目录替换和失败保留语义。

本次不调整服务端 95 秒恢复机制，不增加 iframe/Shadow DOM、自动滚动加载、登录态持久化或新的等待参数。

## 曾考虑的替代方案

**只保留选区及祖先链，删除其他分支。** 样本可缩到 202686 字节，但元素减少到 703，位置序号及 id 匹配集合改变。模型需要把精简定位转换回真实网页，不能保证 extra.js 的定位正确，因此不采用。

**保留全页所有元素，仅清空外围文本。** 可保持更广泛的全局元素匹配关系，但保留了大量后方无关结构。采用正向绝对 XPath 的定位约束后，可以删除后方分支进一步减少输入；不再宣称全局选择器匹配集合不变。

**用少量空兄弟节点维持路径序号。** 只维护部分相对位置，容易让模型把占位属性或缺失后代误当作真实结构。采用原有前方元素结构，不造替代占位节点。

**删除非选区的大属性，仅保留 id/class。** 在保留全页元素的同一样本中可缩到 223466 字节，但破坏 data-*、href 等属性选择器与潜在定位锚点。本方案保留所有留下的元素属性，以减少精简带来的语义差异。

**另写会话根目录 URL 文件。** 当前 capture.json 已拥有对应快照的最终地址，双份记录增加覆盖失败时不一致的可能，因此复用现有记录。

**自动回退到捕获 source.html。** 可能把离线快照预览当作在线提取成功；仅保留用户显式指定的离线入口。

## 后果

正向绝对路径精简前后相同，不等于任意选择器都等价；删除后方分支会改变全局匹配集合、重复 id 数量及倒序位置。外围文本、CSS 和脚本正文也被省略，不能使用这份 HTML 复原页面显示或依赖这些内容的提取。原网站下次访问可能改变前方结构，绝对 XPath 仍需在线验证。选区内部、前方结构或属性本身很大时，体积收益有限；这项精简不解决服务端恢复问题。

固定 5 秒不能保证任意网站已加载全部异步内容，打开原 URL 不会恢复滚动位置、点击状态或临时登录态。重定向、登录页及动态列表可能改变提取结果；失败应如实暴露，不用旧快照数据代替。省略外围内容的 source.html 也不是可重放的完整网站存档。
