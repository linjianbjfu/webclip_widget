# AGENTS.md — 已实施的 Agent Notes

这些 Agent Note 描述已经上线的决策。遵循[根指令](../../../AGENTS.md)和 [Agent Note 格式](../README.md)；`npm run verify-agent-note-format` 门禁检查 lifecycle 相关的结构。

## 让一篇 implemented 的 Agent Note 与实际上线的东西保持同步

在改动它们的同一个改动里，同步路径、符号、默认值和机制。就地重写过时的事实；不要追加变更历史。

当一篇已上线的笔记不太可能再指导未来的工作时，通过 [`archive-agent-notes`](../../skills/archive-agent-notes/SKILL.md) 归档它，而不是继续维护。

### 这不是改写*决策*的许可

就地更新事实层面的落地情况。推翻决策本身或它的理由，需要一篇新的 Agent Note 并互相链接；一篇被完全取代的旧笔记只能通过 [Agent Note 规则](../README.md)里的合并条款删除。
